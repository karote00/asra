# `@asyra/render-engine-pixi`

Official Pixi-backed render-engine provider for the supported 2D
composition.

```ts
import { createPixiRenderEngine } from '@asyra/render-engine-pixi'
```

## Release support

The `0.2.5` ESM artifact supports Node.js 24.x. Use only package-root exports.
See the [Framework release support contract](../../docs/ai/framework/RELEASE_SUPPORT.md).
