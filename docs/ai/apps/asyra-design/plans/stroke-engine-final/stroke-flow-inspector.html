Reading guide, legend, and current debug checklist

How to read this board

  • Read the flow from left to right. Each card is a real pipeline step.
  • Arrows show data moving into the next decision or transformation step.
  • Click a card to inspect helpers, helper conditions, inputs, outputs, risks, tests, implementation trace, and evidence.
  • Use the group filters to isolate one subsystem without changing the underlying flow.
  • Machine-readable flow data lives in stroke-flow-inspector.data.js; this HTML only renders it for human review.

Current debug checklist

  • Shared geometry model is the only geometry truth for fill, stroke, and future shadow.
  • Fill consumes fillRegions; inside/outside dashed stroke consumes strokeBoundaryContours.
  • Hole boundary contours must produce stroke coverage when the stroke rules require it.
  • Each split contour domain owns its dash distribution independently.
  • Product visual must be final/no-overlap; debug overlap is the only raw-fragment mode.

Flow alignment checklist

  • Shared geometry model must be built before fill and stroke consumers.
  • Stroke must consume strokeBoundaryContours, not rebuild self-intersection contours.
  • Fill is a reference consumer only for this stroke fix.
  • Center stroke must not use inside/outside contour-side rules.
  • Product visual must be final/no-overlap; raw fragments are debug-only.
