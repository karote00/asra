# CRDT 7,076 Sample

## One sample URL

Open the App with:

```text
/?fileId=crdt-7076-sample
```

This URL always opens the ordinary socket-authoritative document session. It
does not reject Collaboration, load `document.json.gz` into Core, or select a
local-only startup path. When the socket is unavailable, the App reports the
connection failure in DevTools and continues with the ordinary provisional
local document and durable publication outbox.

Actor A renders the sample by opening the Agent panel, attaching
`reference-image.png`, pasting `instruction.txt`, and pressing Send. The
same-origin action-batch HTTP interceptor matches that request and returns the
checked-in `action-batch.json`, which contains the prepared Group plus 7,075
ordered Vector descriptors. Actor A executes all
7,076 elements through the ordinary Runtime, canonical, Factory, and Render
owners.

With a socket connection, Actor A publishes those ordinary canonical changes
and Actor B receives them through CRDT. Without a socket connection, Actor A
still renders locally and retains the unsent publication in the ordinary
outbox. Both cases use the same URL and HTTP response.

For the maintained single-client render/move/edit regression, run:

```bash
yarn workspace @asyra/asyra-design test:e2e:crdt-7076
```

The command owns an isolated App port with an intentionally unavailable socket,
installs the sample-folder-backed HTTP interceptor, submits the exact request
through the Agent UI, verifies all 7,075 Vectors reach Render, moves the densest
Vector without point mutation, and edits one visible anchor. No derivative
sample or separate manual URL is required.

## Manual render, drag, and Undo check

1. Start the App with the repository's normal local development command.
2. Open
   `http://localhost:3000/?fileId=crdt-7076-sample` (replace the origin only
   when your configured `APP_URL` differs).
3. Open the Agent panel, attach `reference-image.png`, paste
   `instruction.txt`, and press Send.
4. Wait for the complete cat face and the `cat-face` Layer group to appear.
   When the socket is unavailable, the connection error in DevTools is
   expected; the canvas and local action path remain usable.
5. In Layers, select `tabby-vector-0002`. This is the maintained densest sample
   Vector and contains 2,591 point records.
6. Drag it across several pointer updates, then release. The Vector must follow
   the pointer without freezing, distorting, disappearing, or logging
   `[Preset Vector] Render data must contain canonical local Vector geometry`.
7. Press Undo once. The Vector must return to its exact drag-start position
   without deleting the element or requiring repeated Undo presses.
8. Press Redo once. The Vector must return to the final drag position.
9. Repeat the drag and press Escape before mouse-up. The interruption position
   must remain visible; one Undo must restore the drag-start position.

The maintained automated equivalent is
`yarn workspace @asyra/asyra-design test:e2e:crdt-7076`. The canvas-drag
Undo/Redo and commit-current cases are maintained in
`e2e/undo-redo.spec.ts`.

`document.json.gz` is retained only as a generated canonical regression asset
for geometry-heavy formal tests; RenderApp never loads it during sample
startup. It is generated by
`yarn workspace @asyra/asyra-design generate:crdt-7076-document`. The generator
executes the ordinary prepared action and Factory transaction, saves the
resulting canonical document, verifies the 7,076-element count, and compresses
that JSON for the regression fixture.

## Full local Agent and CRDT flow

Start the App through the repository's local development workflow. Start the
reference WebSocket server separately with the App workspace
`collaboration:server` command; root `dev:all` does not start it. Configure
`VITE_COLLABORATION_WS_URL`, then open two App windows with:

```text
http://localhost:3000/?fileId=crdt-7076-sample
```

In Actor A:

1. Open the Agent panel.
2. Attach `reference-image.png`.
3. Paste the complete contents of `instruction.txt`.
4. Press Send.

Opening the URL alone does not create anything. Actor A's ordinary Agent request
sends the image and instruction to the same-origin action-batch backend. After
the backend matches both exact inputs, it returns the checked-in ordered
`action-batch.json` without reading or converting SVG source data.

The checked-in conversion contains 7,075 editable Vector children. The ordinary
App action creates one Group around those children, so Actor A and Actor B each
finish with 7,076 canonical elements.

This sample request does not run VTracer or another image converter. Actor A
executes, renders, and publishes through the ordinary product owners.
Actor B receives and renders the drawing only through CRDT. Actor B creates no
Undo, echo publication, or persistence save; `peer-applied` acknowledges its
completed canonical apply rather than durability.
