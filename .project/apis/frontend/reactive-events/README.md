# API Reference: @asra/reactive-events

This directory provides a detailed reference for the public API of the `@asra/reactive-events` package, categorized by domain.

For architectural details and design patterns, see the documents in `../../architecture/frontend/` and `../../design-principles/`.

## Domain-Specific Functionality

*   **[System Context](./system-context.md)**: Events related to the overall state of the application context (tools, mouse, keyboard).
*   **[Interaction Core](./interaction-core.md)**: Events related to user interactions, decisions, and session management.
*   **[Scene Tree](./scene-tree.md)**: Events related to the scene tree (initialization, data loading, element manipulation).
*   **[Selection](./selection.md)**: Events related to element selection.
*   **[Render](./render.md)**: Events related to rendering (initialization, zoom, pan).
*   **[Props Manager](./props-manager.md)**: Events related to property management (loading, saving, updating).
*   **[UI Context](./ui-context.md)**: Events related to the UI context.
*   **[Core](./core.md)**: Core events like adding elements to the core system.
