# Task Breakdowns (Project Legacy)

This directory contains task decomposition docs used to split one request into smaller executable units.
Primary use cases:
- multi-agent execution
- human/agent collaboration
- parallel delivery and handoff

Task breakdowns are execution-focused documents, not plan trackers.
For current source-of-truth planning, use framework/app plan folders under `docs/ai/framework/plans/` and `docs/ai/apps/*/plans/`.

See `docs/ai/project/AI_WORKFLOW_GUIDE.md` for legacy workflow context.
