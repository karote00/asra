# `@asyra/render`

Engine-neutral render coordination, layers, interaction targets, strategies,
and the public `RenderAdapter`.

```ts
import { RenderAdapter, RenderGraphics } from '@asyra/render'
```

`PixiJSRenderer`, `RenderStrategyGraphic`, and `RenderStrategy` are deprecated
compatibility surfaces for `RenderAdapter`, `RenderGraphics`, and
`EngineNeutralRenderStrategy`.

## Release support

The `0.2.5` ESM artifact supports Node.js 20.x. Use only package-root exports.
See the [Framework release support contract](../../docs/ai/framework/RELEASE_SUPPORT.md).
