# Asyra Framework starter

This is the canonical source for the minimal project generated by
`create-asyra-app`. It is intentionally a React homepage with the Asyra
Framework logo and no product-domain behavior.

From the repository root:

```bash
cd apps/asyra-starter
yarn start
```

Read [`docs/framework.md`](docs/framework.md) before adding Framework packages
or product behavior. Generated projects also include `AGENTS.md` so an AI coding
agent can find the same ownership and verification rules immediately.

## Support and contribution policy
