# Flow Inspector Static Workspace

Reserved implementation root for the static multi-Inspector workspace.

Implementation must follow:

- `docs/ai/tools/flow-inspector/PLANS.md`
- `docs/ai/tools/flow-inspector/plans/flow-inspector-static-workspace-preview-plan.md`

The workspace owns static discovery, sidebar navigation, routing, and selected
Inspector rendering. Dynamic evidence, CI state, commands, actions, and
permissions belong to the future sibling under
`tools/flow-inspector/control-plane/`.
