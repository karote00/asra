# Asyra Design Development Guide

This directory is the portable documentation entry point for humans and AI
agents extending Asyra Design. It is included in projects generated by
`create-asyra-design-app`.

## Read order

1. [`architecture.md`](architecture.md) — ownership and runtime flow.
2. [`development.md`](development.md) — setup, common changes, and checks.
3. [`ai-agent-guide.md`](ai-agent-guide.md) — a bounded agent workflow.
4. [`framework.md`](framework.md) — stable upstream Framework contracts.

The source tree is a maintained reference product, not a Framework fork. Keep
design-tool behavior in this App and use only public Asyra package entrypoints.

## Owner map

| Concern                                    | Owner path                                     |
| ------------------------------------------ | ---------------------------------------------- |
| Registered interaction or command behavior | `src/features`                                 |
| Reusable canonical mutation/query route    | `src/common-apis`                              |
| UI-triggered orchestration                 | `src/controllers`                              |
| Startup, registration, and composition     | `src/init`, `src/startup.ts`                   |
| App constants and input configuration      | `src/constants`, `src/config`                  |
| App overlays and render projections        | `src/render-layers`, `src/render-app`          |
| Optional AI actions and presentation       | `src/ai`                                       |
| Collaboration session and wire policy      | `src/collaboration`, `collaboration-server.ts` |
| Durable document reference service         | `server`, `vite.document-backend.config.ts`    |

If a change needs a Framework capability that is not public, confirm the
upstream Framework owner before adding the smallest public facade. Do not reach
into package internals from the App.
