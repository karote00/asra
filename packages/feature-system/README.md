# `@asyra/feature-system`

Deterministic feature registration, execution, priority, exclusivity, and
session lifecycle for app-owned interaction behavior.

```ts
import { defineFeature, getFeature } from '@asyra/feature-system'
```

## Release support

The `0.2.5` ESM artifact supports Node.js 24.x. Use only package-root exports.
See the [Framework release support contract](../../docs/ai/framework/RELEASE_SUPPORT.md).
