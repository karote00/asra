# Committed Stroke Artifacts

Put only durable, curated stroke evidence here.

Allowed examples:

- small fixtures consumed by tests
- final rule evidence linked from the active inspector or README
- concise diagnostic summaries kept as decision evidence

Do not store local iteration dumps, Playwright output copies, videos, traces, or
manual crop experiments here. Those belong in `../transient/`, `../tmp/`,
`../local/`, or `../debug/`.
