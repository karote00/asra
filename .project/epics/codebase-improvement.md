# EPIC: Codebase Improvement

This guide is for users who have an existing codebase and want to improve its quality, such as refactoring, fixing bugs, or adding tests. The AI will assist in analyzing the codebase, identifying areas for improvement, and implementing changes.

## Phase 1: Codebase Analysis & Problem Identification

-   AI will analyze the existing codebase to identify potential issues (e.g., code smells, performance bottlenecks, missing tests, bugs).
-   AI will present findings and collaborate with the human to prioritize areas for improvement.

## Phase 2: Planning & Strategy

-   AI will propose strategies for addressing identified problems (e.g., refactoring patterns, testing methodologies, bug-fixing approaches).
-   Human will approve the proposed plan.

## Phase 3: Iterative Implementation & Verification

-   AI will implement changes incrementally, focusing on the agreed-upon improvements.
-   AI will assist in writing new tests or updating existing ones to verify changes.
-   Human will review implemented changes and verification results.

## Phase 4: Documentation Update

-   AI will update relevant documentation (architecture, API, design principles) to reflect the codebase improvements.
