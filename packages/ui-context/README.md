# `@asyra/ui-context`

Framework and app state projection for UI consumers without transferring
canonical state ownership to presentation code.

```ts
import uiContext from '@asyra/ui-context'
```

## Release support

The `0.2.5` ESM artifact supports Node.js 24.x. Use only package-root exports.
See the [Framework release support contract](../../docs/ai/framework/RELEASE_SUPPORT.md).
