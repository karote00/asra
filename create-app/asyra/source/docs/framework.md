# Build with Asyra Framework

This starter intentionally contains only a React homepage. Add Framework
packages and product behavior as your requirements become concrete.

Use these upstream source-of-truth documents:

- [Framework getting started](https://github.com/karote00/asyra/blob/main/docs/ai/framework/GETTING_STARTED.md)
- [Public documentation](https://github.com/karote00/asyra/blob/main/docs/public/index.md)
- [API surfaces](https://github.com/karote00/asyra/blob/main/docs/ai/framework/API_SURFACES.md)
- [Architecture](https://github.com/karote00/asyra/blob/main/docs/ai/framework/ARCHITECTURE.md)
- [Golden paths](https://github.com/karote00/asyra/tree/main/docs/ai/framework/golden-paths)
- [Hard rules](https://github.com/karote00/asyra/tree/main/docs/ai/framework/rules)
- [Release support](https://github.com/karote00/asyra/blob/main/docs/ai/framework/RELEASE_SUPPORT.md)

Start by modeling one App-owned domain concept and one registered Feature. Add
only the Framework packages used by that composition and preserve the canonical
intent path documented upstream.
