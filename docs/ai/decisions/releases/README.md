# Cross-Cutting Release Decisions

This directory stores repo-wide decisions by release timeline.

Use this scope only when a decision spans:

1. Framework + one or more apps.
2. Multiple apps.
3. Global governance/process contracts for all scopes.

## Files

1. `unreleased.md`
- Ongoing cross-cutting decision log.

2. `vX.Y.Z.md` (or project release tag)
- Snapshot file for released cross-cutting decisions.

## Entry Template

- Date
- Title
- Context
- Decision
- Consequences
- Related Scope Docs
- Related Commit(s)
